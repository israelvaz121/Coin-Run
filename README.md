# COIN RUN

O Coin Run é um jogo que eu desenvolvi como um projeto de programação, com a ideia de colocar em pratica alguns dos conhecimentos que venho aprendendo e também aprender mais sobre desenvolvimento de jogos.

## Sobre o projeto

No jogo, o jogador controla o personagem e precisa coletar as moedas espalhadas pelo mapa enquanto tenta avançar pelo jogo e superar os desafios.

A ideia do projeto começou de uma forma mais simples e foi crescendo conforme eu ia adicionando novas mecanicas e testando novas coisas.

Foi um projeto que me ajudou bastante a entender melhor lógica de programação e a interação entre os elementos de um jogo.

## Como jogar

O objetivo principal é coletar as moedas e conseguir avançar pelo mapa.

Durante o jogo, é preciso controlar o personagem e desviar dos obstaculos para conseguir completar o percurso.

### Controles

| Tecla     | Ação                  |
| --------- | --------------------- |
| `W` / `↑` | Mover para cima       |
| `A` / `←` | Mover para a esquerda |
| `S` / `↓` | Mover para baixo      |
| `D` / `→` | Mover para a direita  |

## Funcionalidades

* Sistema de coleta de moedas
* Controle do personagem
* Sistema de mapa e fases
* Interação com obstaculos
* Sistema de pontuação
* Sistema de reinicio da partida
* Mecânicas de movimentação e interação

## Tecnologias

O projeto foi desenvolvido utilizando as tecnologias presentes no codigo do jogo.

Durante o desenvolvimento, tentei fazer as mecanicas por conta propria para entender melhor como cada parte do jogo funciona.

## O que eu aprendi

Desenvolver o Coin Run me ajudou a entender melhor como transformar uma ideia em um projeto que realmente funciona.

Durante o desenvolvimento, pratiquei lógica de programação, estruturas condicionais, funções, movimentação de objetos, colisões e sistema de pontuação.

Também percebi que coisas que parecem simples quando estamos jogando podem dar bastante trabalho para programar, e que muitas vezes é necessario fazer varios testes até funcionar do jeito que eu queria.
